# 멀티시그 지갑 프론트엔드

이 프로젝트는 Vite, React, TypeScript, Tailwind CSS를 사용하여 구축된 멀티시그 지갑의 프론트엔드입니다.

## 기술 스택

- Vite
- React
- TypeScript
- Tailwind CSS

## 시작하기

### 개발 환경 설정

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build

# 미리보기
npm run preview
```

### 폴더 구조

```
frontend/
```
